# Tone: Friendly

**Essence:** Warm, conversational, and approachable — like a real person who'd genuinely
enjoy working together. Still professional, just less formal.

**Do:**
- Write the way you'd talk: natural, relaxed, easy to read.
- Use contractions freely and a warm, personable opener.
- Show genuine interest in the recipient's work.

**Don't:**
- Tip into unprofessional territory — no slang dumps or excessive exclamation points.
- Use emojis.
- Be so casual that the value or the ask gets lost.
